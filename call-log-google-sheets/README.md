# 통화 기록 -> 구글 시트 자동 기록 (텔레그램 봇)

모바일에서 텔레그램으로 전화번호를 입력하거나, 통화기록 캡처 사진을 보내면
지정된 구글 시트에 **날짜 / 전화번호 / 통화시작 / 메모** 가 자동으로 한 줄 추가됩니다.

## 왜 텔레그램인가

- 클로드 앱을 따로 열 필요 없이 텔레그램만 켜면 됨 (진짜 자동화, 상시 대기)
- 파싱 규칙이 코드로 고정되어 있어 매번 결과가 일관됨
- Google Apps Script를 서버로 쓰기 때문에 **호스팅 비용 0원**

## 시트에 기록되는 컬럼

| 날짜 | 전화번호 | 통화시작 | 메모 | 사진 | 등록시각 |
|---|---|---|---|---|---|

- 사진을 보낸 경우, OCR로 읽은 원본 캡처 사진은 구글 드라이브에 저장되고 링크가 "사진" 칸에 남습니다.
- 문자로 날짜/시간이 명시되어 있지 않으면 메시지를 보낸 시각을 자동으로 사용합니다.

## 입력 예시

텍스트로 아무거나 편하게 보내면 됩니다. 예:

```
01012345678 14:30 보험 상담, 콜백 요청함
```

```
010-1234-5678
```

캡처 사진만 보내도 되고, 사진 + 캡션(메모)을 함께 보내도 됩니다.

## 설정 방법

1. **구글 시트 생성**
   - 새 스프레드시트를 만듭니다 (이름 자유).

2. **Apps Script 연결**
   - 시트에서 `확장 프로그램 > Apps Script` 클릭
   - 기본 `Code.gs` 내용을 이 폴더의 [`Code.gs`](./Code.gs) 내용으로 교체

3. **Drive API 고급 서비스 활성화** (OCR에 필요)
   - Apps Script 편집기 좌측 `서비스` 옆 `+` 클릭 -> `Drive API` 추가

4. **텔레그램 봇 생성**
   - 텔레그램에서 `@BotFather` 검색 -> `/newbot` 으로 봇 생성 -> 토큰(token) 복사

5. **스크립트 속성 등록**
   - Apps Script 편집기 -> `프로젝트 설정` -> `스크립트 속성` -> `속성 추가`
     - `TELEGRAM_BOT_TOKEN` : 4번에서 받은 토큰
     - `ALLOWED_CHAT_ID` : 아래 7번에서 확인한 chat_id (스팸 방지를 위해 꼭 등록 권장). 여러 명이 쓸 경우 콤마로 구분해서 입력 (예: `111,222,333`)
     - `SHEET_NAME` : 기록할 시트 이름 (생략 시 자동으로 "통화기록" 시트 생성)

6. **웹 앱으로 배포**
   - `배포 > 새 배포 > 유형 선택: 웹 앱`
   - 실행: 나 / 액세스 권한: 모든 사용자
   - 배포 후 나오는 웹 앱 URL을 복사

7. **텔레그램 webhook 등록 + 본인 chat_id 확인**
   - 브라우저에서 아래 주소로 한 번 접속해 webhook 등록:
     `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<웹앱URL>`
   - 텔레그램에서 봇에게 아무 메시지나 한 번 보낸 뒤, 아래 주소로 접속:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
   - 응답 JSON에서 `"chat":{"id": ...}` 값을 찾아 5번의 `ALLOWED_CHAT_ID`에 입력

8. **테스트**
   - 봇에게 전화번호 텍스트를 보내고 시트에 기록되는지 확인
   - 통화기록 캡처 사진을 보내고 OCR 인식 결과를 확인 (인식률이 100%는 아니므로 봇의 응답 메시지로 결과를 확인 후 필요시 시트에서 직접 수정)

## 참고

- `ALLOWED_CHAT_ID`를 등록하지 않으면 봇 토큰과 URL을 아는 누구나 시트에 기록을 남길 수 있으니 반드시 등록하세요.
- 나중에 사용자를 추가하고 싶으면, 추가할 사람이 봇에게 메시지를 한 번 보낸 뒤 `getUpdates`로 그 사람의 chat_id를 확인해서 `ALLOWED_CHAT_ID` 값 끝에 콤마로 이어붙이면 됩니다. 스크립트 재배포 없이 속성 값만 수정하면 바로 적용됩니다.
- OCR 인식률은 사진 화질/폰트에 따라 달라집니다. 필요하면 사진의 캡션에 정확한 전화번호를 직접 적어 보내면 캡션이 우선 파싱됩니다.
